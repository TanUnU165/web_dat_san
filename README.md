
# Dự án Đặt Sân Bóng (LVTN_DatSanBanh)

## Mô tả

Dự án **Đặt Sân Bóng** là một ứng dụng web cho phép người dùng đặt sân bóng — xem lịch trống, đặt giờ, quản lý đặt sân, quản trị sân, v.v. Mục tiêu là đơn giản hóa việc quản lý đặt sân bóng cho người dùng và chủ sân.

---

## Tính năng chính

- Xem lịch sân trống / đã đặt  
- Đặt sân theo khung giờ  
- Quản lý các sân (thêm, sửa, xóa)  
- Quản lý đặt sân (duyệt, hủy, theo dõi trạng thái)
- Quản lý giải đấu (thêm, sửa, cập nhật, hiển thị lịch sử).
- Hệ thống tài khoản: người dùng & quản trị 
---

## Công nghệ sử dụng
- **Ngôn ngữ**: PHP
- **CSS Framwork**: Tailwind
- **Cơ sở dữ liệu**: MySQL
